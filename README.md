# Mirror Recorder

**Mirror Recorder** — клиентский мод для **Minecraft 1.12.2 / Forge**, который записывает действия игрока и затем воспроизводит их.

> 🎥 Мод повторяет **реальный ввод игрока**, а не симулирует физику или перемещение напрямую. Благодаря этому воспроизведение остаётся привязанным к обычной игровой механике Minecraft.

**GitHub:** https://github.com/Dedlock500543/Mirror-RecorderMod
**Скачать проект (ZIP):** https://github.com/Dedlock500543/Mirror-RecorderMod/archive/refs/heads/main.zip

## 📦 Установка

1. Установите **Minecraft Forge 1.12.2**.
2. Поместите `Mirror-Recorder-1.12.2-1.0.0.jar` в папку `mods`.
3. Запустите Minecraft.

Мод работает **только на клиенте**.

> **Не устанавливайте Mirror Recorder на сервер.** Серверная установка не требуется и не поддерживается.

## 📁 Расположение файлов

Все пути указываются относительно игрового каталога:

* `.minecraft`
* каталога инстанса MultiMC / Prism Launcher
* CurseForge и других лаунчеров

Мод получает путь к игровому каталогу через Forge и не использует сторонние директории.

| Назначение      | Путь                             |
| --------------- | -------------------------------- |
| Конфигурация    | `config/mirror_recorder.cfg`     |
| Записи          | `mirror_recorder/slot_N.nbt`     |
| Резервные копии | `mirror_recorder/slot_N.bak` |
| Временные файлы | `mirror_recorder/slot_N.tmp` |
| Экспорт         | `mirror_recorder/exports/*.mrr`  |
| Корзина         | `mirror_recorder/trash/`         |
| Диагностика     | `logs/mirror-debug.log`          |

Корзина хранит до **100 последних удалённых записей**.

### Диагностика

Лог `logs/mirror-debug.log` включается настройкой `debug` в `config/mirror_recorder.cfg`.

Флаги JVM `-Dmirror.debug=true` и `-Dmirror.debug.csv=true` включают диагностику **принудительно**: пока флаг задан,
лог нельзя выключить настройкой — помогает только перезапуск игры без флага.

CSV-выгрузка (`mirror-debug.csv`) пишется рядом с игровым каталогом и ограничена 200 000 строк.

## 🎮 Управление

Клавиши Mirror Recorder **по умолчанию не назначены**, чтобы избежать конфликтов с другими модами.

Назначить их можно в:

**Настройки → Управление → Mirror Recorder**

Также все основные действия доступны через команды.

| Команда                         | Действие                              |
| ------------------------------- | ------------------------------------- |
| `/mirror gui`                   | Открыть главное окно                  |
| `/mirror record <слот>`         | Начать запись                         |
| `/mirror play <слот>`           | Воспроизвести запись один раз         |
| `/mirror loop <слот>`           | Запустить циклическое воспроизведение |
| `/mirror limit <слот> <N>`      | Установить количество циклов          |
| `/mirror stop`                  | Остановить запись/воспроизведение     |
| `/mirror list`                  | Показать занятые слоты                |
| `/mirror name <слот> <имя>`     | Переименовать запись                  |
| `/mirror delete <слот>`         | Удалить запись                        |
| `/mirror marker <слот> [текст]` | Установить описание записи            |

### Слоты

* Всего доступно: **100 слотов**
* Максимальный размер записи: **72 000 кадров**
* При 20 TPS это составляет примерно **1 час записи на слот**

## 🎥 Запись и воспроизведение

Mirror Recorder записывает действия игрока и воспроизводит их в том же порядке.

В запись могут попадать:

* движение;
* повороты камеры;
* клики;
* прыжки;
* переключение слотов хотбара;
* чат;
* команды;
* действия внутри игровых интерфейсов.

Мод **не телепортирует игрока** и не заменяет игровую физику собственной симуляцией.

### Скорость

Доступный диапазон:

**0.25× → 4×**

При пропуске кадров:

* нажатия воспроизводятся в исходном порядке;
* поворот камеры берётся из последнего кадра соответствующего такта.

> 🧭 Стабилизация маршрута доступна только при скорости **1.0×**.

---

## 🧭 Стабилизация маршрута

Mirror Recorder поддерживает ограниченную стабилизацию маршрута.

Она работает **только через обычный игровой ввод** и не использует телепортацию или прямое изменение координат игрока:

* включается настройкой «Стабилизация маршрута» в **Настройки → Повтор**;
* работает только при скорости **1.0×** — при другой скорости мод сообщает, что стабилизация выключена;
* если отклонение превысило **3 блока**, повтор останавливается с сообщением (в полёте на элитрах лимит мягче —
  **16 блоков** и до 2 секунд терпения, потому что физика полёта догоняет маршрут сама);
* коррекция на элитрах ограничена 0.35 блока за тик.

### Таймер правого клика

Ваниль держит паузу правого клика (по умолчанию 3 тика) и может «съесть» следующий записанный клик.
При точной установке блоков мод выравнивает этот таймер (3 → 4 тика), чтобы повтор ставил блоки в том же темпе,
что и живая рука игрока. Это единственное место, где мод вмешивается в ванильный таймер.

## 🏠 Автовозврат

После завершения воспроизведения мод может автоматически вернуться к точке старта.

Доступны два варианта:

* локальное выравнивание;
* использование **Baritone**, если он установлен.

Baritone **не является обязательной зависимостью** и подключается через рефлексию.

## 🌍 Переходы между мирами

Запись может продолжаться через переходы между мирами.

Например:

**лобби → портал → игровой мир**

Всё сохраняется в одном файле записи.

При воспроизведении переход должен произойти **реально**, так же как во время записи:

* через портал;
* через игровой интерфейс;
* через команду;
* другим обычным игровым способом.

После загрузки нового мира воспроизведение продолжится.

## 🧰 Игровые интерфейсы

Mirror Recorder записывает действия внутри игровых окон.

Поддерживаются, например:

* выбрасывание предметов;
* раскладка предметов цифрами;
* закрытие окон клавишами;
* ввод текста на наковальне;
* ввод текста на табличках;
* действия в сундуках;
* действия в верстаках;
* другие клики внутри игровых GUI.

### Важно

Клики в контейнерах повторяются по **записанному положению курсора** и только в окне того же типа.

Содержимое контейнера не проверяется.

Поэтому, если предметы находятся в других слотах, тот же клик может попасть по другому предмету.

### Буфер обмена

Комбинации `Ctrl` в текстовых полях не воспроизводятся.

Например, вставка текста из системного буфера обмена не переносится в запись.

## 💬 Чат и команды

Воспроизведение чата отправляет **реальные сообщения и команды** на сервер.

> ⚠️ На публичных серверах автоматизация ввода может быть запрещена правилами сервера.

### Команды

Всё доступно из чата командой `/mirror`:

| Команда | Что делает |
| --- | --- |
| `/mirror record <слот>` | начать запись в слот |
| `/mirror play <слот>` | воспроизвести запись один раз |
| `/mirror loop <слот>` | воспроизводить по кругу |
| `/mirror limit <1–5>` | сколько кругов до остановки |
| `/mirror pause` | пауза и продолжение повтора |
| `/mirror stop` | остановить запись или повтор |
| `/mirror selftest` | автотест движка: события и метки времени |
| `/mirror list [страница]` | показать слоты 1–100 |
| `/mirror delete <слот>` | удалить запись (сначала в корзину) |
| `/mirror name <слот>` | задать имя слота |
| `/mirror marker <слот>` | задать метку слота |
| `/mirror gui` | открыть окно мода |

### Безопасность записи чата

Запись чата по умолчанию **выключена**.

Это предотвращает случайное сохранение в записи:

* личных сообщений;
* паролей;
* другой чувствительной информации.

Функцию можно включить в:

**Настройки → Повтор**

### Импортированные записи

Чат и команды из **импортированных `.mrr`** не отправляются вообще.

Таким образом, чужая запись не сможет:

* написать сообщение в чат;
* выполнить команду от вашего имени.

При попытке воспроизвести такой кадр мод один раз сообщает об этом в чат.

> Свои записи работают как обычно.

## 🩹 Повреждённые записи

Повреждённая запись не обязательно становится полностью недоступной.

Мод пытается открыть её частично:

* повреждённые кадры пропускаются;
* исправные кадры продолжают воспроизводиться;
* информация о количестве потерянных кадров записывается в журнал диагностики.

Это позволяет восстановить максимально возможную часть записи.

## 🔨 Сборка из исходников

Для сборки требуется **JDK 8**.

### Windows

```bat
set "JAVA_HOME=<путь-к-вашему-JDK-8>"
gradlew.bat --no-daemon build
```

### Linux / macOS

```bash
export JAVA_HOME=<path-to-your-jdk8>
./gradlew --no-daemon build
```

После успешной сборки:

```text
build/libs/Mirror-Recorder-1.12.2-1.0.0.jar
```

JAR уже реобфусцирован:

```gradle
jar.finalizedBy('reobfJar')
```

Для проверки проекта:

```bash
gradlew runClient
```

Рабочий каталог клиента:

```text
run/
```


## ⚠️ Важные ограничения

Mirror Recorder воспроизводит **ввод**, а не заранее рассчитанный результат.

Поэтому поведение записи может измениться, если состояние игры отличается от состояния во время исходной записи.

Например:

* изменилось содержимое контейнера;
* изменилось расположение объектов;
* другой мир находится в ином состоянии;
* произошли дополнительные загрузки или задержки;
* игровой интерфейс отличается от исходного.

Особенно это важно для кликов по контейнерам: мод повторяет записанную позицию курсора, но не проверяет, какой предмет находится в этом месте.
